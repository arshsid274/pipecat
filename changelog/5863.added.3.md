- Added `LLMClassifier`, which answers classifier questions with any Pipecat LLM service. The LLM runs in a pipeline inside a small worker the classifier creates for it, `LLMClassifierWorker`, and answers each question by calling a tool, so the result is structured. The worker is attached to whatever worker the classifier is set up with and starts and stops with it.

  ```python
  classifier = LLMClassifier(llm=OpenAILLMService(model="gpt-4o-mini"))
  detector = VoicemailDetector(classifier=classifier)
  ```
