- Added classifiers, small objects that answer a typed question about some state: `yes_no()`, `choice()` among options, or `score()` on a rubric. `BaseClassifier` in `pipecat.classifiers` defines the questions and their result types. `JevClassifier` answers them through Jev, TypeSafe's classification model, and several classifiers can share one `JevClient`, the HTTP/2 layer that handles auth, retries and token accounting. Install with `pip install pipecat-ai[jev]`.

  ```python
  classifier = JevClassifier(api_key=os.getenv("JEV_API_KEY"))
  result = await classifier.choice(
      "I'd like to book a table for, um",
      {"complete": "the user finished", "short": "a brief pause", "long": "asked for time"},
      "is the user's turn over?",
  )
  ```
