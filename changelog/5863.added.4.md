- `UIWorker` takes an optional `classifier`. `should_respond(event)` asks it whether a UI event calls for the assistant to speak, using the event and the latest screen snapshot, so a click that needs no comment costs one small question instead of an LLM turn.

  ```python
  @ui_event("nav_click")
  async def on_nav(self, message):
      if await self.should_respond(message):
          ...
  ```
